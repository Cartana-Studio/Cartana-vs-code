# Create a New Project

Follow these steps to create a new project:

**Open cartana Extantion**  
    Press cartana Extention icon in the sidebar to Create new application or  Open Existing one.
<video controls src="20250504-1614-19.1519093.mp4" title="Create New Application"></video>

**Set the Project Location**  
    Browse to the desired folder or create a new one for your project.
<video controls src="20250510-1948-03.0543684.mp4" title="Select Project Location"></video>
Cartana Extention has templates for the following languages – `cpp`, `cpp-low-level`, `go`, `javascript`, `lua`, `python`, `ruby`, `rust`, and `typescript`.

<video controls src="20250510-1952-46.7012529.mp4" title="Title"></video>

After creating your application, you can start building your dApp by adding your logic to the main file.

**Choose from list of languages**  
    Select a project template from the available options.

<video controls src="20250510-2000-31.8545688.mp4" title="Title"></video>

This will creates a new directory for your dapp with essential files for your dApp development.

- `Dockerfile`: Contains configurations to build a complete Cartesi machine with your app's dependencies. Your backend code will run in this environment.

- `README.md`: A markdown file with basic information and instructions about your dApp.

- `dapp.py`: A Python file with template backend code that serves as your application's entry point.

- `requirements.txt`: Lists dependencies required for your application.

**Name Your Project**  
    Enter a name for your project when prompted.
    
**Initialize the Project**  
    Wait for the setup process to complete. including installing dependencies and generating files.
