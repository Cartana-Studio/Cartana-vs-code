# Dashboard View

This folder contains the React-based UI for the dashboard data provider. 
It displays Action Button for Runing, Building and Compile appliction.

## Files

- `Dashboard.jsx`: React component for the dashboard.
- `index.js`: Entry point for the React application.
- `index.html`: HTML file to host the React app.

## Usage

1. Build the React app using a bundler like Webpack or Parcel.
2. Serve the `index.html` file in the VS Code webview.
